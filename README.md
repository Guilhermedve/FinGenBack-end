# FinGen

FinGen é uma API construída com [Nest](https://github.com/nestjs/nest) framework TypeScript.

## Descrição

FinGen é um sistema de geração financeira desenvolvido com NestJS, TypeScript e seguindo as melhores práticas de desenvolvimento backend.

## Instalação

```bash
$ npm install
```

## Executando a aplicação

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Testes

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Estrutura do Projeto

```
src/
├── app.controller.ts      # Rotas da aplicação
├── app.module.ts         # Módulo raiz
├── app.service.ts        # Lógica de negócio
└── main.ts              # Ponto de entrada
```
